# MyAcademyPortfolioCore

**Kişisel Portföy ve Blog Uygulaması | ASP.NET Core 9.0**

MyAcademyPortfolioCore, ASP.NET Core kullanılarak geliştirilmiş **dinamik, modern ve yönetilebilir bir kişisel portföy & blog web uygulamasıdır**. Bu proje, eğitim sürecinde öğrendiğim .NET teknolojilerini, Entity Framework Core ile veritabanı yönetimini ve modern web tasarımını bir araya getirerek pratik bir şekilde uygulamama olanak sağlamıştır.

---

## 🎯 Projenin Amacı

- Kendi portföyünüzü ve projelerinizi sergileyebileceğiniz bir web platformu oluşturmak.
- Kullanıcılar için blog yazıları yayınlamak ve yönetmek.
- Admin paneli üzerinden içerik yönetimi yapmak (projeler, blog yazıları, yetenekler vb.).
- Modern web standartlarıyla responsive tasarım uygulamak.

---

## 🧩 Özellikler

- **Kullanıcı Paneli**
  - Ana sayfa ve hakkında bölümü.
  - Blog yazıları ve detay sayfaları.
  - Yetenekler ve projelerin listelenmesi.
  - İletişim formu ile mesaj gönderme.

- **Admin Paneli**
  - Rol tabanlı kullanıcı yönetimi (Admin / Kullanıcı).
  - Blog yazıları ekleme, düzenleme, silme.
  - Projeler ve yetenekler üzerinde CRUD işlemleri.
  - Gelen mesajları görüntüleme ve yönetme.

- **Dinamik Özellikler**
  - Yeteneklerin yüzdelik değerlerine göre renkli progress bar gösterimi.
  - Blog ve proje içeriklerinin veritabanından dinamik çekilmesi.
  - SweetAlert2 ile kullanıcı dostu bildirimler.
  - Responsive ve mobil uyumlu tasarım (Bootstrap 5).

---

## 🛠 Kullanılan Teknolojiler

| Katman | Teknolojiler |
|--------|--------------|
| Backend | ASP.NET Core 9.0, C#, Entity Framework Core, LINQ |
| Frontend | HTML5, CSS3, Bootstrap 5, jQuery, Font Awesome, SweetAlert2 |
| Veritabanı | Microsoft SQL Server, EF Core Code First |
| Güvenlik | ASP.NET Identity, Rol Bazlı Erişim Kontrolü |
